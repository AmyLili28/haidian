来源

假设

  • A-CONTROLS-001 — 建筑规模、开发强度、空间供给策略只能作为方向性设计。
  • A-CONTROLS-002 — The package can be reviewed as a formal AI submission only for provided official boundaries and submitted design layers; statutory controls still need professional confirmation.
  • A-BOUNDARY-001 — 空间边界和面积指标仅供设计讨论和自检，不得作为 official redline 或精确面积依据。
  • A-BOUNDARY-002 — 西界为 provisional 概念扩展区，不得作为审批红线；spatial review 的 KEY_AREA_BEYOND_PROVISIONAL_SITE 为已知 minor 提示。
  • A-FIGURE-HERO-001 — 该图仅用于 proposal/visual 的概念表达与叙事氛围，不得作为空间边界、建筑体量或实施效果的证据。
  • A-FIGURE-DATA-001 — 评审空间证据以数据图为准；AI 仅可用于 hero 等概念氛围 inset，且须单独披露。
  • A-DATA-CONTEXT-001 — 现状覆盖以正文披露与有限 OSM 道路裁切为参考；设计指标与 Gate1 仅基于 submitted design layers，不将开放数据 bulk import 当作设计成果。
