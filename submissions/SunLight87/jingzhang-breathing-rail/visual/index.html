百年为基，城市叠代。 以铁路遗产和公共生活为“一基”，把创新校准、日常共译与城市转化组织成“三场”，由两翼导入资源与扩散能力，再以十二个可暂停、可回退的城市原型持续学习。这里的“叠代”不是增加一层炫技，而是让每一次介入都能被看见、被质疑、被修正。

01 / CONCEPT GRAMMAR

一基、三场、两翼、十二原型

这是一个概念关系语法，不是红线、地块、道路、工程或运营承诺。它把“遗产如何继续成为公共基础设施”转译成可协作、可验证、可撤回的城市设计语言。

frozen concept / v3
● 关系示意，不代表真实地理位置或精确比例同源数据：GeoJSON · metrics · evidence

叠代的定义

“叠”是把铁路遗产、公共生活、创新产业和可信智能并置为可辨识的时空层；“代”是让每次介入可验证、可修正、可撤回、可升级。

因此，城市设计不提供唯一答案，而是建立一套能把不同候选放在同一张证据桌上比较的工作面。

一条决策句先看来源，再看约束；先做小试，再决定是否扩散。

03 / THREE KEY AREAS

05 / AGENT IN PRACTICE

Agent 不是画图按钮：五个责任环节把规划做实

在真实城市规划中，Agent 负责把多源资料、空间约束和方案比较组织成可审查的工作流；它生成候选、暴露冲突、记录证据，但不代替规划师、公众、产权人、专业机构或法定审批。

clear · constrain · generate · compare · decide
01 / CLEAR INPUT

清权输入

读取现状影像、GeoJSON、规划条件、用户痛点与数据许可，拆出已知、未知和临时项。

输出：来源台账、假设、待补问题 · 人工确认授权与权威版本
02 / CONFLICT MAP

约束 / 冲突

把文保、交通、无障碍、消防、产权、环境、隐私与数据权利转为可检查规则，标出冲突和停止阈值。

输出：约束矩阵、冲突清单、不可自动化事项 · 专业复核边界
03 / MULTI-SCALE

多尺度方案族

从总体到片区再到节点生成可比较的空间关系、路径、体量与服务接口，不把一个原型误写成一栋建筑。

输出：总体—片区—节点候选族、平面—剖面—人视表达 · 人工选择候选
04 / PARETO + NEGATIVE

Pareto / 负例

并列比较可达性、公共空间、环境风险、维护与实施条件，主动展示不可行或不应采用的负例。

输出：取舍依据、风险说明、反例记录 · 独立专业与公众质询
05 / HUMANDECISION

HumanDecision

责任人记录采用、暂停、拒绝、回滚或试验；小规模反馈回到校准，证据不足就不扩散。

输出：签署状态、版本、反馈、退出条件 · AI 不代签，审批另行进行
真实规划的核心不是“AI 自动给出最终方案”，而是让每一次生成都有输入、有约束、有对比、有反例、有责任人和可撤回路径；这也是“第一次真实城市规划，交给 Agent”最应被看见的部分。

09 / AI DESIGN OPERATING SYSTEM

AI 生成候选，人类决定是否进入城市

智能化不等于自动审批。方案的可复用能力来自固定输入、约束检查、方案族比较、独立批评和可回退记录，而不是一张看似确定的生成图。

machine candidate → human decision
01 / INTAKE

清权输入

收集来源、许可、空间关系、用户痛点和未知项；缺资料不静默补齐。

02 / CONSTRAINT

约束检查

检查文保、无障碍、通行、隐私、消防、数据授权和临时几何边界。

03 / GENERATE

候选方案族

机器生成可比较的关系、路径提示、组件或时段组合，而非唯一答案。

04 / CRITIQUE

独立复核

专业与公众从可达性、包容性、风险和证据一致性进行反向质询。

05 / HUMAN GATE

HumanDecision

责任人记录依据、状态、取舍、暂停、拒绝、回滚或批准；AI 不代签。

06 / LEARN

试验与回滚

小规模可逆试验，保留人工替代、停止按钮、反馈记录和 sunset 触发条件。

10 / WHY THIS PLACE

把场地的六个断点，变成六个设计动作

京张遗产公园的线性连续性、横向接口和多主体条件要求“连续但有接口”的空间策略；城市叠代把技术边界直接转成公共空间体验。

problem → response
01

遗产可读性断点

以“一基”保存时间、来源与记忆；导视和数据牌展示版本，不用未经授权的历史肖像或故事替代史料。

02

公园—街区接口断点

以“三场”组织南北连续、东西接口和日常服务；关系线是待核验接口，不宣称新路、桥隧或站点工程。

03

数据可信断点

在校准场共置、标注置信度、记录模型卡和极端值红队；未校准读数不升级为监管或医疗结论。

04

自动化服务断点

在共译场把模型输出翻译为纸质、语音、静态和人工等效路径；不能退出就不发布。

05

创新落地断点

在转化场先做可移动、可暂停的服务原型，经过反馈再决定是否采用；工程、消防、物业条件另行核验。

06

治理责任断点

两翼导入标准、法务、运维和场景能力；每个原型绑定责任、停止条件、回滚路径和复盘记录。
